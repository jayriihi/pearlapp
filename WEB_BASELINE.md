This document captures the state of the Pearl web application at the time the
Pearl Island weather station first went live.

At this point, the site reflects the core, working functionality required to
display live wind data from the new station and its existing fallbacks. No
post-launch enhancements, refinements, or additional features have been added
beyond what was required for initial public operation.

This baseline exists to provide a clear reference for how the site behaved at
station startup, prior to any subsequent feature development or UI changes.
